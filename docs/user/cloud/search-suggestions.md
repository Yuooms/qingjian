搜索联想缺省关闭。打开后，输入拼音时会定期把已敲的拼音字母发送给搜索建议接口（缺省为 Bing），
取回的中文词补入候选列表。词库中没有的人名、地名、新词因此也能打出来，不必事先导入词库。

只发送拼音字母，不发送输入上下文，也不发送候选；密码框中绝不发送。
与[云联想](index.md)是两套独立的开关，可同时开启，两路结果一并补入候选末尾。暂仅 Windows 可用。

## 开启

「设置 → 搜索联想」：打开开关，可调整联想词格数、接口地址、市场、最少字母数、停键延迟与请求超时。

填写完成后点「测试联通」，将以当前地址与市场查询一次固定拼音，结果显示在按钮右侧：成功时显示建议条数与耗时，失败时显示原因。
输入法由系统启动，不读取终端中设置的代理；若需通过代理访问，请在系统设置中设置系统代理。

## 候选词

停键 200 毫秒后，接口给出的词补入候选第一页**末尾**两格（「搜索联想」页可调为 1 至 9），
带云朵标记，数字键正常选择，上屏消耗整段拼音。

- 前面的本地候选位置不变，`Space` 上屏的仍是本地首选。
- 只保留整条都是汉字、且字数与所敲音节数相同的建议：`yisitalu` 取「伊斯塔露」，不取「伊斯塔露是谁」「伊斯塔露cos」。
- 未返回、无结果、超时、连不上均不改变显示，不预留、不画占位。
- 选中词库中没有的联想词会记为用户词（按所敲的读音记录），下次本地直接给出。
- 所敲字母不能切成完整拼音时不查询：简拼（`fhyq`）、形码编码（`ggll`）、末尾还没打完的音节（`kaif`）都属这种。
- 少于设定的字母数（缺省 2）不查询。

## 与云联想的区别

| | 搜索联想 | [云联想](index.md) |
|---|---|---|
| 服务 | 搜索建议接口，无需密钥 | 用户自行填写的 AI 服务商，需密钥 |
| 发送的内容 | 拼音字母 | 拼音字母、光标前后文本、本机候选 |
| 得到的结果 | 词 | 词、整句补全、问字答案、译词 |

两者可同时开启。同时开启时先补搜索联想的结果，再补云联想的结果；两边给出同一个词时只显示一条。

## 不联想的情况

上屏之后不联想；英文模式、以 `v` 开头的算式不联想；密码框中不联想。
